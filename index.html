Detection methodology

Five failed logins from the same source and user within five minutes generate a high-severity alert. A subsequent successful login within that window is flagged for review. Access denials and file changes are informational rules. Alerts are indicators, not proof of intrusion. Import only synthetic or authorized logs; do not publish sensitive data.
